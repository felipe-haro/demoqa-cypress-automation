published as a GitHub Issue with severity, priority and area labels.
The consolidated view with rationale is in [DEFECTS.md](../../DEFECTS.md).

Every report follows the same template: Summary, Environment, Preconditions, Steps to reproduce, Expected and
Actual result, Severity/Priority with rationale, Reproducibility, Evidence (screenshot, automated check and failure
output), Workaround, Notes / suspected cause, and acceptance criteria for the fix.
